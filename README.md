# 🤖 HR Policy Assistant | Retrieval-Augmented Generation (RAG)

A simple **Retrieval-Augmented Generation (RAG)** application that allows users to ask questions about an HR policy document and receive context-aware answers generated by an LLM.

Instead of relying entirely on the LLM's pre-trained knowledge, this application retrieves relevant information from the provided HR policy document and uses it as context to generate accurate, relevant responses.

## 🧠 How RAG Works

The application follows a simple workflow:

1. **Document Loading:** Load the HR policy document (`data/hr_policy.txt`).
2. **Text Splitting:** Divide the document into smaller, manageable chunks.
3. **Embedding Generation:** Convert each text chunk into numerical vector representations using Jina AI embeddings.
4. **Vector Storage:** Store the embeddings and their corresponding text chunks in a FAISS vector database.
5. **Retrieval:** When a user asks a question, retrieve the most relevant chunks based on semantic similarity.
6. **Answer Generation:** Pass the retrieved context and user's question to the Groq-powered LLM to generate a relevant answer.

## 🛠️ Tech Stack

| Component | Technology | Purpose |
|---|---|---|
| Programming Language | Python | Application development |
| Data Source | HR Policy Document | Knowledge base |
| Embedding Model | Jina AI | Generate text embeddings |
| Vector Database | FAISS | Store and retrieve embeddings |
| LLM Provider | Groq | Generate contextual answers |
| Framework | LangChain | Manage the RAG workflow and agent |

## ⚙️ Prerequisites

Before running the notebook, make sure you have:

- Python installed.
- A virtual environment named `ragenv`.
- VS Code with the Jupyter extension (or Jupyter Notebook).
- A Groq API key.
- A Jina AI API key.

### 1. Configure Environment Variables

Create a `.env` file in the project root directory:

```env
GROQ_API_KEY=your_groq_api_key
JINA_API_KEY=your_jina_api_key
```

### 2. Select the Python Kernel

Make sure the notebook is using the `ragenv` virtual environment as its Python kernel.

In VS Code, select the kernel from the top-right corner of the notebook.

### 3. Install Dependencies

Install the required packages using your virtual environment:

```bash
pip install -r requirements.txt
```

## 🚀 Running the Application

1. Open `hr_policy_assistant.ipynb`.
2. Select the `ragenv` kernel.
3. Ensure the `.env` file contains valid API keys.
4. Execute the notebook cells sequentially.
5. Start asking questions about the HR policy document.

## 📌 Key Takeaway

This project demonstrates how to build a basic document-based AI assistant using RAG.

The central idea is simple: **Retrieve relevant information first, then generate an answer using that information.**

This approach helps make LLM responses more relevant to a specific knowledge base and reduces reliance on potentially unrelated pre-trained knowledge.
